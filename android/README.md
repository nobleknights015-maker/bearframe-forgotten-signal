# Ghost Signal Engine — Android host (development scaffold)

This is a thin Android WebView host of the **existing** HTML5 Canvas engine. It does not replace Ghost Signal's JS runtime, presentation, missions or Sprite Studio. Gradle copies \`frontend/public/**\` into generated APK assets at build time, so code and assets have one source of truth.

**Build prerequisites:** Android SDK platform 35; JDK 17; Gradle 8.10.2 or the equivalent Android Gradle Plugin 8.8.2-compatible Gradle runtime. From repository root run \`gradle -p android :app:assembleDebug\` for the public Ghost Signal Engine build (which excludes \`assets/aeon/story/**\` by default). The debug APK outputs to \`android/app/build/outputs/apk/debug/app-debug.apk\`. No signing key is checked in, and this is **not** a production signed build.

**Owner-private offline Aeon Circuit APK:** On an owner-controlled machine after running \`node frontend/narrative-tools/build_full_campaign.mjs\` with local private source files, run \`gradle -p android :app:assembleDebug -PaeonOfflineBuild=true\` (or \`:app:assembleRelease -PaeonOfflineBuild=true\` with your private keystore). This packages the compiled campaign bundle offline, sets \`applicationId\` to \`labs.bearframe.aeoncircuit\`, labels the app \`Aeon Circuit: The Silent Wake\`, and boots \`campaign.html\` directly with zero runtime JSON import. Keep owner-private APKs and private source files out of public repositories and public CI artifacts.

**Persistence:** \`WebViewAssetLoader\` gives an app-controlled stable HTTPS-like origin, rather than a \`file://\` origin that can break JS imports/local storage. The untouched Ghost Signal keys remain under that origin. New RPG saves use the separate two-slot \`bearframe_ghost_signal_rpg_v1:A/B\` namespaced journal. They are not automatically migrated from browser saves. App upgrades preserve local WebView storage when signed consistently; uninstall/clear-data can erase it. Native persistence and SAF export/import are still a release-gate requirement, not implemented here.

**Build verification:** [GitHub Actions run 43630442334](https://github.com/nobleknights015-maker/bearframe-ghost-signal/actions/runs/43630442334) successfully built `app-debug.apk` and uploaded the `ghost-signal-engine-android-debug` artifact (CI ZIP approximately 4.2 MB). The workflow provisions Android SDK platform 35 directly rather than installing the discontinued SDK `tools` package. **Known remaining blockers:** this APK has not been installed and run in an emulator or on the physical Moto G (2025); performance and save continuity are unverified. The original HTML requests Silkscreen/VT323 from Google Fonts; offline presentation will require licensed local font assets before claiming pixel-identical offline UI. Check viewport safe areas, system bars, touches, gamepads, audio, controller navigation and a >30-minute save soak on the target device. APK installation/update needs consistent signing; do not embed private signing material in git.

**Interface lock:** Keep \`frontend/public/index.html\`, \`css/game.css\`, \`js/ui.js\` as the original visual source of truth; add RPG views in matching style, never replace the Ghost Signal UI.


**Host lifecycle and safe surface:** The host reserves Android system-bar/camera-cutout insets around the existing WebView rather than changing the logical game size. Immersive bars are restored when focus returns. On Android pause it emits `ghost-signal-host-pause` on `window` before pausing the WebView; input releases held keyboard/controller/touch directions and queued actions. The game flow owns pause/save handling for this event. Back dispatches a complete Escape key press. The emulator smoke also exercises HOME/background and same-process resume before force-stop/relaunch, and records a resume screenshot. These changes require Android compilation and emulator/physical-device validation; Node input regression tests verify only the JavaScript release/pointer behavior.
